# Maritime Emergency SOS Standard Operating Procedures

## Protocol Hierarchy
1. **Immediate Broadcast**: Send distress coordinates to nearest Indian Coast Guard MRCC (Maritime Rescue Coordination Centre).
2. **VHF Channel 16 Alert**: Broadcast verbal Mayday on VHF 156.8 MHz.
3. **Local Coastal Police**: Alert Coastal Security Police Station via 1093.
4. **Peer Vessel Relay**: Nearby AIS vessels receive automated proximity broadcast.
