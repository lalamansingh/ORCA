# Potential Fishing Zone intelligence

ORCA obtains PFZ geometry from the official INCOIS PFZ WebGIS public WFS. The provider normalizes returned GeoJSON before storing it in PostGIS. A PFZ is never generated by ORCA or an LLM.

`/api/v1/pfz/nearest` calculates distance against actual advisory geometry with PostGIS `ST_Distance`, finds the closest point with `ST_ClosestPoint`, and calculates bearing from that point. `/api/v1/pfz/geojson` is the map source, and `/api/v1/pfz/{id}` returns evidence and source metadata.

Run `python -m app.scripts.refresh_pfz` to ingest the configured provider. It is deliberately not run on request; operators may schedule it at `PFZ_REFRESH_INTERVAL_MINUTES`. Each fetch creates a `DataSourceLog`.

INCOIS WFS supplies an advisory year/day and geometry, but no explicit expiry or reliable sector label. ORCA leaves `valid_until` null and labels a record CURRENT only while its advisory day is within `PFZ_MAX_ADVISORY_AGE_HOURS` (48 hours by default). Older records are STALE. This is a freshness policy, not a claimed source-validity period.

Demo data is available only with `ORCA_DEMO_MODE=true` and visibly labelled `DEMO DATA`. A failed live source is reported as unavailable, never as no PFZ.

Sources: [INCOIS PFZ WebGIS](https://incois.gov.in/geoportal/MFASPFZ/index.html) and [INCOIS Marine Fisheries PFZ service](https://incois.gov.in/MarineFisheries/PfzWebGis).
