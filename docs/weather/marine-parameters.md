# Marine Meteorological Parameter Guidelines

## Key Environmental Indicators
- **Significant Wave Height ($H_s$)**: Calm ($<1.2\text{m}$), Moderate ($1.2-2.0\text{m}$), Rough ($>2.0\text{m}$).
- **Wind Speed**: Beaufort force scale 0 to 12. Speeds $>35\text{ km/h}$ warrant advisory.
- **Sea Surface Temperature (SST)**: Optimum pelagic front ranges $27.5^\circ\text{C} - 29.5^\circ\text{C}$.
- **Current Velocity**: Surface drift vectors in $\text{m/s}$.
