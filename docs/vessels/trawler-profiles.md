# Indian Marine Fishing Vessel Class Profiles

## Vessel Categories
1. **Traditional Non-Motorized (Vallam / Kattumaram)**: 0-5 NM range, manual oar/sail.
2. **Motorized Craft with Outboard Motor (OBM)**: 5-15 NM range, 9.9 - 25 HP.
3. **Mechanized Trawler / Gillnetter (IBM)**: 15-50 NM range, 100-150 HP inboard.
4. **Deep-Sea Tuna Longliner**: 50-200 NM EEZ range, multi-day endurance.
