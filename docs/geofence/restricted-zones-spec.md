# Maritime Geofencing & Restricted Zones Specification

## Monitored Zone Categories
- **Naval Firing Ranges**: Periodic exclusion zones with active NOTMAR notices.
- **Marine Protected Areas (MPAs)**: Ecological sanctuaries (e.g. Gulf of Mannar Biosphere).
- **International Maritime Boundary Line (IMBL)**: Strict high-risk boundary line notification.
- **Port Harbor Approvals**: Fairway security corridors and anchorages.
